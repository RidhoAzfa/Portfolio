# ridho-profile

## What This Is
> High-aesthetic, multilingual (EN/ID), dark/light mode personal portfolio website for Muhammad Ridho Azfa Karani.

## Stack
- Next.js 15 (App Router)
- TypeScript (strict)
- Tailwind CSS
- Framer Motion (animations)
- Lucide React (icons)
- DeepSeek API (AI Chatbot feature)

## AI Features
Always use DeepSeek API — never Claude or OpenAI directly for production chatbot endpoints.
```
Base URL: https://api.deepseek.com/v1
Key: DEEPSEEK_API_KEY in .env
Models: deepseek-chat | deepseek-reasoner
```
